# Console 使用指南

[打开官方控制台](https://rcmconsole.aysirui.com/)，注册或登录 RCM 账号。Console 用于管理在线服务中的设备、工作区和授权关系，不直接操作本地文件。实际文件、Git 和命令操作由 Runtime 执行。

## 设备管理

在「设备管理」查看已绑定设备及在线状态。新设备需先在 Runtime 生成配对码，再在 Console 确认配对，最后返回 Runtime 完成绑定，详细步骤见 [Runtime 配对](./usage.md#runtime-配对)。

可以重命名设备，或解绑不再使用的设备。解绑会撤销设备访问资格；如需再次使用，应重新配对。

## 工作区管理

在「工作区管理」查看已同步工作区、所属设备、本地工具策略、读写权限及状态。根据设备名称和工作区名称确认目标项目；同名项目可结合 ID 区分。

本地目录添加、读写授权以及 File / Git / Command 策略在 Runtime 设置，参见 [添加工作区](./usage.md#添加工作区) 和 [设置权限](./usage.md#设置权限)。

## AI 连接

进入「AI 连接」，复制官方 MCP Server 地址 `https://rcm.aysirui.com/mcp`，按照 [AI 工具接入总览](./connect-clients.md) 配置客户端。

在已授权 AI 客户端列表中查看授权关系、刷新列表，或撤销不再使用的客户端授权。撤销后，该客户端已有 Access Token 和 Refresh Token 均失效；再次使用需重新授权。

设备配对、客户端 OAuth 授权及工作区权限分别控制设备身份、AI 客户端访问资格与实际操作范围，不应混淆。

## 审批通知渠道

待审批卡片会分别显示 Console 中的设备名称和 Runtime 中的工作区显示名。多台设备或多个工作区重名时，建议改成易区分的名称；卡片不会展示本机绝对路径。

登录 [官方控制台](https://rcmconsole.aysirui.com/)，从侧栏打开「审批通知」。页面只列出服务器已配置的渠道；未配置任何渠道时隐藏菜单，直接打开 `/console/approval-channels` 会提示暂不可绑定。

- **飞书**：选择「绑定飞书」，通过分享链接打开机器人私聊。外部用户按飞书提示申请使用并开启单聊；内部用户也可在飞书搜索已发布且对自己可见的机器人。
- **企业微信**：选择「绑定企业微信」，在可用企业范围内打开官方控制台提供的智能机器人私聊。若有分享链接，可直接从 Console 打开；需在机器人的企业可用范围内。
- **钉钉**：选择「绑定钉钉」，在可用企业范围内打开已发布的应用机器人私聊，或使用官方控制台提供的链接。当前不支持借此接入未配置的其他企业。

配置了机器人分享链接时，绑定窗口会显示二维码，也可复制链接或直接打开。扫码只打开机器人入口，不会自动订阅。

1. 点击「复制完整指令」，将整行粘贴到机器人私聊并发送。必须保留「绑定」两个字、后面的空格和绑定码；只发送绑定码不会收到回复。
2. 把机器人回复里的 32 位确认码填回 Console。确认码不是上一步发出的绑定指令，两者都必须在同一个五分钟有效期内使用。

无需手动查用户 ID。绑定后默认启用，可独立开关多个已绑定渠道。暂停或解绑会使该渠道的旧卡片失去决定权限。

同一条审批会向每个启用的渠道私发一张卡片。每条待审批请求都可以在机器人或 Runtime UI 批准、拒绝，第一个有效决定生效。命令通知会展示完整程序和参数、工作目录，以及未登记命令的一次性授权范围。遇到超长、客户端显示不全或不适合在消息中显示的详情时，请在 Runtime 核对。飞书和钉钉主动更新原卡。企微会另发一条简短的结算文本，只包含审批结论和审批编号；在点击回调窗口内也会更新原卡。平台可能留存卡片和其中的完整命令。

## 操作记录

在「操作记录」查看工具操作、所属工作区和设备、执行结果、耗时及执行时间。点击详情查看可用的执行信息，遇到错误可根据错误码定位权限、连接、审批或命令执行问题。

记录只保留必要的脱敏审计信息，不保存完整文件正文、AI 对话、工作目录或命令输出。命令摘要的脱敏规则及错误码参见 [Runtime 使用指南](./usage.md#命令执行)；详细数据边界见 [工作区权限与数据流向](./workspace-permissions.md)。

## 常见问题

- 设备离线：检查目标设备的 Runtime 是否启动并连接当前 Server。
- 工作区缺失：确认 Runtime 已针对当前 Server 授权该项目。
- AI 客户端授权缺失：确认 OAuth 使用同一个 RCM 账号，刷新授权列表。
- 没有审批通知入口：当前 Server 可能尚未配置通知渠道，可直接在 Runtime 处理审批。
