# Remote Code MCP 文档

Remote Code MCP（RCM）让 MCP 客户端在你授权的范围内，通过远程 Server 访问本机代码工作区。

## 从这里开始

- [使用指南](./usage.md)：配置 Runtime、配对设备、授权工作区，以及管理审批和 AI 客户端连接。
- [部署指南](./deployment.md)：配置环境、部署 Server 与 Console，以及验证服务。
- [许可证说明](./licensing.md)：了解项目许可证、版权和分发要求。
